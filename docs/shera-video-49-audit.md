# Shera Video 49: physical action and location audit

Video 49 is `PRJ-02645`, output `ASTV-05672` (30 seconds, 6 selected clips). It is an exported review cut, not a verified commercial. Its first beat places the mascot at a dining table; sampled frames show an implausible seat/table relationship. Its fifth beat wipes a wet surface although the current script has no preceding liquid event. The peach room is sparse, and generated locations differ from the more grounded living-room view in `PRJ-02642`/`PRJ-02644`.

The older Shera family (`PRJ-02501`, including `PRJ-02593` and `PRJ-02642`) did not establish a fully accepted physical-action solution. Open feedback still calls out water wiping, chair/table support, paw anatomy, package perspective, and continuity of the glass. Those records were passed to Video 49 as historical examples; they did not constitute an enforceable quality check on its new screenplay or frames.

Shared pipeline changes following this audit:

- `validate_script` now rejects an unsupported cleaning/fluid effect even when automatic writing collects advisory findings, and rejects a wet-surface clean-up without an earlier liquid event. A dry prop dropping cannot satisfy that cause.
- Creative direction requires coherent depth, material texture, practical lighting and visible physical support in broad shots unless the input asks for a spare set.
- First-frame and sampled-take checks ask whether the actor is visibly supported by the authored seat or floor. A clear support failure receives a bounded automatic retry; ambiguous or subjective findings remain recorded for review.
- The rejected Video 49 output has version-bound owner feedback for its physics and setting. A replacement batch, `CRB-00046` / `PRJ-02647`, uses the original mascot and package references without the old generated peach/white location pictures.

These checks improve admission and feedback transfer, but sampled vision cannot certify every frame or guarantee correct cloth/liquid dynamics, anatomy, printed product information or art direction. Judge the replacement's final timeline visually before treating it as an accepted advertisement.

The first replacement keyframe run (`RUN-01012`) exposed another blocker: four source-art preparation attempts rejected generated scenes containing two to five apparent product packs, so no protected frame was accepted for those shots. The shared draw prompt now explicitly requires one physical advertised object in its authored position, with packaging characters confined to flat print. This is a prompt-level reduction of duplicate candidates, not proof that the image model will comply. The bounded automatic redraw and source-art protection must both succeed before a clip can be counted as valid.

Direct inspection of those rejected scene images showed a more basic mismatch: the location generator interpreted a lived-in room with a reachable table and chair as a bedroom. Several frames then seated the mascot on or through the bed edge, while the script described floor/table staging. Location generation previously saw only the short setting label, not the upcoming shot compositions. It now receives a bounded summary of the shot openings and uses the existing vision observer to reject a plate whose furniture or support geometry contradicts them. A rejected plate gets one different seed; if both fail, the system does not inject that wrong room into every first frame. This is a shared location rule, independent of Shera.

## Product-reference binding defect (Video 49)

The incorrect pack in Video 49 shot 3 was not a successful source-art retention result that later drifted: its frozen generation input contained only the Character and Environment references. The original product asset (`ASTV-03698`) was absent, so the first-frame generator had no source package pixels to protect and reconstructed the Shera logo, mascot print, lettering and pack geometry from text. The resulting image is therefore invalid for brand use.

Production planning now performs a final, model-agnostic reference grounding pass after the actual image/video prompts are resolved. If the resolved shot visibly names a pack, packet, package, carton, box, dispenser, bottle, tube, pouch or branded product container, it automatically binds its matching Product reference (or the sole Product reference). The same pass applies to both AI Director and Follow-the-sheet workflows. A tissue-only material insert does not pull in a package that is not visible. Once a Product reference is bound, the existing reference-retention path inserts and records original source artwork before H3 receives the first frame. Regression tests cover the visible-pack and tissue-only cases. A new run is still required; it cannot repair the already exported Video 49 frames.
